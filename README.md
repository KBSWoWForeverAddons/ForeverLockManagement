# Forever Lock Management

**Forever Lock Management** is a clean, lightweight Warlock utility addon for **WoW Forever** (`16001` / Classic / TBC) built from the ground up with a compact vertical hub, working Soul Shard bag management, customizable chat announcements, and center-screen warning icons.

## Features

- **Compact Vertical Warlock Hub:** Movable, scalable vertical shard-capacity gauge with quick-access buttons for **Healthstone / Ritual of Souls**, **Soulstone**, **Mount**, and combat-safe pull-out drawers for **Demons**, **Curses**, **Buffs & Utility**, and **Firestone / Spellstone**.
- **Soul Shard Bag Management (Bags 1–5):** Assign any bag (1–5) for Soul Shards, auto-sort shards into your assigned bag out of combat, cap shards to your assigned bag's capacity (or a custom 1–32 limit), and highlight/destroy excess shards with a single right-click on the Shard Manager button.
- **Customizable Speech Announcements:** Built-in default announcements for Ritual of Summoning, Soulstone (+ optional whisper), Ritual of Souls, Demon Summoning, and Mounts—with an in-game **Custom Speech Editor** and local chat preview (`/flm speech`) so you can personalize every line.
- **Center-Screen Warning Icons:** Movable alert icons with optional sound for **Shadow Trance (Nightfall)**, **Backlash**, **Demon / Elemental Targets**, and **Anti-Fear** (safely handles WoW Secret Values restrictions).

## Slash Commands

- `/flm` or `/lock` — Open Options
- `/flm sort` — Sort Soul Shards into assigned bag
- `/flm destroy` — Destroy excess Soul Shards
- `/flm speech` — Preview speech lines locally in chat
- `/flm customspeech` — Open Custom Speech Editor
- `/flm test` — Toggle movable warning icon preview
- `/flm reset` — Reset hub and warning positions
